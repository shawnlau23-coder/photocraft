PhotoCraft with SGL Tools portable mode

While this file sits next to photocraft.exe, PhotoCraft with SGL Tools keeps its preferences,
brush presets, crash-recovery autosaves and startup state in the PhotoCraftData folder beside
it, and writes nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PhotoCraft
with SGL Tools with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\PhotoCraftSGL for
settings and %LOCALAPPDATA%\PhotoCraftSGL\Recovery for crash-recovery autosaves. If
PhotoCraftData can't be written (for example on a read-only drive), PhotoCraft with SGL Tools
says so and uses those folders instead.
